# Pet Social Platform

Мобильная платформа для социализации домашних питомцев и их владельцев.

## Структура проекта

- `android-app/` — Android-клиент
- `backend/` — backend API на Go
- `docs/` — проектная документация
- `.env.example` — пример переменных окружения

## MVP модули

- auth
- profile
- pets
- matching
- chat
- routine
