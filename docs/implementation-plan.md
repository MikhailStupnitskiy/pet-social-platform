# План дальнейшей реализации PetSocial

## Цель

Довести текущий MVP до демонстрируемой версии, соответствующей ТЗ и ПМИ: авторизация, профиль, питомцы, мэтчинг, чаты, рутина, социальная лента, хэндлеры/услуги, уведомления, изображения и базовая монетизация.

## Текущий статус

- Реализованы backend-модули `auth`, `profile`, `pets`, `matching`, `chats`, `routine`, `feed`.
- Android-клиент подключён к REST API через Retrofit/Hilt и содержит экраны основных MVP-разделов.
- Социальная лента пока поддерживает только публикации без комментариев и реакций.
- Хэндлеры, заявки на услуги, уведомления, загрузка изображений в MinIO и подписка пока отсутствуют.
- Автотестов почти нет; Go-пакеты компилируются, Android-сборка требует локального Gradle cache для стабильной проверки в sandbox.

## Приоритеты реализации

1. Стабилизация текущего MVP:
   - исправить битые строки интерфейса и технические подписи с ID;
   - добавить минимальные backend unit tests для сервисов auth/pets/matching/feed;
   - зафиксировать команды локальной проверки.

2. Улучшение социальной ленты:
   - добавить комментарии к публикациям;
   - добавить реакции/лайки;
   - отобразить счётчики и список комментариев в Android.

3. Изображения:
   - подключить MinIO в `docker-compose.yml`;
   - добавить backend endpoint для загрузки изображений;
   - заменить ручной ввод `image_url` в Android на выбор изображения.

4. Хэндлеры и услуги:
   - добавить профили хэндлеров, услуги, заявки и статусы заявок;
   - добавить Android-раздел для поиска хэндлеров и управления заявками.

5. Уведомления и завершение ПМИ:
   - добавить системные события о мэтчах, сообщениях и заявках;
   - добавить экран уведомлений или индикаторы в существующих разделах;
   - подготовить сценарии ручных испытаний по ПМИ.

6. Подписка и монетизация:
   - добавить модель подписки пользователя;
   - ограничить расширенные возможности флагом подписки;
   - для дипломной демонстрации использовать mock payment flow без реального эквайринга.

## Проверка

- Backend: `GOCACHE=../.gocache GOMODCACHE=../.gomodcache go test ./...` из `backend/`.
- Android: `GRADLE_USER_HOME=../.gradle-user ./gradlew.bat testDebugUnitTest --no-daemon` из `android-app/`.
- Интеграционно: поднять PostgreSQL через Docker, применить миграции, пройти сценарии регистрации, создания питомца, мэтчинга, чата, рутины и публикации.
